# Blog illustrations

Created with the built-in image generation tool for Elf Mailroom. Each article uses its own illustration, shared across all five languages, with localized alt text. No stock photography was used.

The production WebP images and 640 px variants live in `public/assets/blog/`. Full-size assets are 1536 × 1024 px. Smaller copies are used through responsive `srcset`; the full-size asset is also used in social metadata and article structured data.
